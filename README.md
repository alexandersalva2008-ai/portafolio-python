# Automatizaciones en Python

Soy Alexander, desarrollo desde La Piedad, Michoacán.

Construyo herramientas que le quitan trabajo manual a negocios y despachos contables: extracción de datos web a Excel, consolidación de CFDI en reportes, automatización de tareas repetitivas.

Trabajo **local**: los datos del cliente no salen de su computadora. Precio cerrado por proyecto, dividido en hitos: 30% al arrancar, 70% al aprobar. Entrega con código documentado y una llamada de 15 minutos para que el cliente lo opere solo.

## Casos

| Caso | Qué resuelve |
|---|---|
| [01 - Extractor de precios](01-extractor-precios/) | Extrae precios de competidores a Excel con historial. |
| [02 - Resumen de CFDI](02-resumen-cfdi/) | Consolida cientos de XML en un Excel por cliente y por mes. Sin captura manual. |
| [03 - Bot de citas](03-bot-citas/) | Agenda citas por formulario y avisa por Telegram de las próximas 24 horas. |

## Servicios

- Scraping de precios y datos públicos a Excel/CSV, con historial
- Consolidación y limpieza de datos en Excel
- Resumen mensual de CFDI para despachos contables
- Automatización de reportes y tareas repetitivas
- Scripts a medida en Python
