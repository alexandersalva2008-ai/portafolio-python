# Reglas del repo

Portafolio de automatizaciones Python. Cada carpeta es un caso independiente.

## Convenciones
- Python 3.11, sin frameworks salvo FastAPI cuando el caso lo pida.
- Dependencias en requirements.txt por carpeta. Nada global.
- Codigo y comentarios en espanol. Nombres de variables en espanol.
- Cada caso lleva README.md con: Problema, Uso, Ejemplo de salida.
- Datos de prueba en carpeta ejemplos/. Nunca datos reales.
- Salida siempre a archivo (xlsx, csv, json). Nunca solo a consola.

## Reglas de trabajo
- No explores el repo completo. Solo los archivos que te nombre.
- No expliques lo que hiciste. Solo lista archivos creados y como correrlo.
- No refactorices lo que ya funciona. No agregues tests salvo que se pidan.
- Si falta un dato, asume lo obvio y sigue. No preguntes.
- Detente cuando termines. No propongas mejoras.
